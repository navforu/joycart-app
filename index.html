Everyday use

Use cases

Built for the feeling of buying from a shared link — not for real checkout.

  • Share a product into the app

    In Amazon, Flipkart, or the browser, tap Share on a product and pick JoyCart. The page opens in-app.

  • Paste a link on Home

    Drop an https URL into the field and Open. JoyCart scrapes the title, image, and price when it can.

  • Fake Buy Now / Add to Cart

    Both storefront buttons and JoyCart’s own bar go to a pretend cart or checkout. No merchant is contacted.

  • Edit price and currency

    If the scrape is wrong, tap the bottom bar and set the amount and currency yourself (₹, $, £, and more).

  • Pretend cards stay on the device

    Saved cards and the delivery address persist locally. Orders and the cart vanish when the app closes.

  • Amazon-ish or Flipkart-ish chrome

    Switch the store look on Home so the pretend shop matches the link you shared.

Engineering

How it’s built

The Android source stays private. This public repo only holds the showcase, license, disclaimer, and APK releases.

Private

navforu/fake-ecomm-droid

Kotlin / Jetpack Compose app, unit tests, version.properties, and the release.yml workflow that publishes here.

Public

navforu/joycart-app

This site (GitHub Pages), screenshots, MIT license, disclaimer, and every JoyCart-x.y.z.n.apk on Releases — overwritten from public/ on each successful publish.

  1. Push to private main

    CI bumps the version, runs JVM unit tests, and builds a release APK.

  2. Publish only if tests and build succeed

    Pull requests stop after test/build. On main, a PUBLIC_REPO_TOKEN checks out joycart-app, syncs the private repo’s public/ folder with rsync, and pushes.

  3. GitHub Release + APK

    CI creates tag vMAJOR.MINOR.PATCH.BUILD on the public repo, attaches JoyCart-….apk and a .sha256 checksum, then commits the new version.properties back to the private repo.

Versions handle themselves

Releases use MAJOR.MINOR.PATCH.BUILD. Every publish increments the last digit unless you flip a bump flag before pushing.

# version.properties in the private repo
VERSION=0.0.0.4
BUMP_MAJOR=false  → 1.0.0.0
BUMP_MINOR=false  → 0.1.0.0
BUMP_PATCH=false  → 0.0.1.0
# all false → regular build: 0.0.0.4 → 0.0.0.5
# past .99 carries left: 0.0.0.99 → 0.0.1.0
# versionCode = M·1e6 + N·1e4 + P·100 + B (always increases)
